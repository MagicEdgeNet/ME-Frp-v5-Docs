# ME Frp 内容策略与文档站优化设计

日期：2026-11-13
适用工作区：`ME-Frp-v5-Frontend`、`ME-Frp-v5-Docs`
目标分支：前端 `feat/autoTLS-and-security`；文档站 `feat/standalone-docs`

## 目标与边界

本次工作分为两个仓库工作流：

1. 优化前端统一策略页中的内容策略文案；不修改已确认的协议日期/主体、隐私政策条款及其他产品功能。
2. 优化独立文档站的 Mermaid 首次渲染、全文搜索、移动端 topbar、穿透类型说明及页面 SEO。继续使用现有 Vue/Vite、Marked、Mermaid 和静态文档生成体系，不引入服务端搜索或不必要的大型依赖。

所有改动按功能拆成清晰提交，在指定分支验证后推送其现有 upstream。不得强推、改写历史或删除分支。

## 1. 内容策略

- 保留现有禁止内容、敏感内容、特殊业务资质要求、流量与 BT/PT 限制、违规处理及前置防御规则，不因措辞优化而缩窄适用范围。
- 统一主体称谓、标点、术语、标题层级和规则表达，减少重复语句，保留必要示例及处理方式。
- 对受管控网络穿透，明确事前授权、授权范围、遵守审批和安全措施、最小权限、凭证保管、禁止越权访问、事件处置及平台按风险采取措施。
- 必要新增仅限于帮助用户理解既有合规边界和安全责任的具体说明；不新增无依据的监控能力、数据收集承诺、绝对免责或任意处罚承诺。
- 保留已确认的运营主体和日期：极致锐联（深圳）科技有限公司；2021 年 7 月 15 日生效；2026 年 11 月 13 日更新。

## 2. Mermaid 首次渲染

在独立文档站当前的 Mermaid 初始化配置中显式使用 Dagre 布局，保持图表源码、动态渲染、主题同步、SVG 安全清理及可折叠源码区不变。

验收通过浏览器网络请求监听确认首次打开包含 Mermaid 图表的文档时不请求 ELK 相关 chunk 或资源；同时检查 SVG 图表、节点标签、深浅主题及源码折叠仍正常。

## 3. 全站本地全文搜索与响应式 topbar

### 搜索索引

- 构建阶段复用现有 Markdown 编译结果，为所有面向用户公开的文档文章生成轻量搜索数据。字段至少包含路径、标题/导航标题、摘要、正文可读文本及可用于结果预览的标题或匹配片段。
- 搜索覆盖正文段落、标题、表格及有意义的代码示例文本；移除 Markdown 标记和 HTML 标签，避免把原始语法符号当成内容。
- 默认收录 `manifest.groups` 中所有用户可访问文章；排除 `index:false` 的内部首页模板和测试页，保持其 `noindex` / 内部用途。
- 索引作为静态构建产物提供，不调用面板 API。搜索数据在首次打开搜索框时按需加载并缓存；加载失败时提供明确、可恢复的提示。
- 排序优先级为标题/导航标题、摘要、正文；多词查询要求各词均命中。结果提供标题、摘要和正文命中片段并跳转到文章；不要求新增复杂模糊匹配或外部依赖。

### 顶栏与搜索弹窗

- 桌面与移动端共用一个搜索入口和搜索弹窗状态；移动端顶栏保留品牌、菜单及可直接触达的搜索按钮，菜单导航和主题控制在窄屏下保持清晰。
- 从首页正文移除嵌入式搜索框，避免重复入口；保留正文中常见主题、协议和文档目录等导航内容。
- 搜索弹窗在桌面居中显示，在手机屏幕使用可读的近全宽布局，处理安全区域、键盘弹出、内容滚动、关闭和焦点管理。
- 支持 Ctrl/Cmd+K、Escape、上下键选择、Enter 打开结果；提供可访问标签、加载/无结果/错误状态和移动端触控目标。
- 测试涵盖桌面与手机 topbar、弹窗打开/关闭、焦点、键盘操作、全文片段、所有公开文章可被检索，以及首页不再出现正文搜索。

## 4. 穿透类型支持状态

检查首页、穿透类型说明、术语表及其他引用，统一明确 ME Frp 当前暂不支持 STCP、SUDP、XTCP。可以保留它们作为 Frp 上游概念的简短解释，但必须明确与平台当前支持范围的区别；不得继续将其列为可选择的 ME Frp 服务类型或推荐配置。已支持的 TCP、UDP、HTTP、HTTPS 说明保持准确并检查交叉链接。

## 5. 页面标题与 SEO

- 为所有公开文档页面统一 title 规则（文章标题加站点名），并保证客户端路由导航和静态 HTML 构建输出一致；首页、404、重定向页采用各自合适标题。
- 检查每个可索引静态页的唯一 description、robots、canonical、Open Graph、Twitter metadata 与结构化数据；修正重复、空缺或 SPA 导航后陈旧的值。
- 保持 sitemap 仅列出规范、可索引页面；排除测试页和重定向页，保留合法重定向目标。
- SEO 文案遵循可读性优先，不堆砌关键词；结构化数据只使用页面实际存在的标题和描述。
- 单测与构建验收遍历全部公开 manifest 页面，验证 title/meta/JSON-LD/canonical/sitemap 的完整性及一致性，并检查 SPA 页面切换时动态 head 信息同步更新。

## 6. 分批交付与验证

建议提交批次：

1. 前端：内容策略文案与安全说明。
2. 文档站：Mermaid Dagre 布局及对应浏览器验收。
3. 文档站：构建期全文搜索索引、topbar/modal 和移动端适配。
4. 文档站：穿透类型支持状态与相关首页/术语更新。
5. 文档站：title、meta、canonical、结构化数据及 SEO 检查。

每个批次只暂存其明确涉及的文件，运行相应的检查；最终运行 Docs 的 `pnpm test`、`pnpm run test:build`、`pnpm run typecheck`、生产构建及 `pnpm run test:browser`。如已有浏览器验收服务占用端口，使用独立端口并报告给当前预览会话，不中断其他进程。所有批次通过后，在相应目标分支提交并推送；远端写入若遇保护规则、冲突或非快进拒绝则停止，不强推。

## 验收结果

- 用户已确认设计及完整实施范围；搜索仅收录 `manifest.groups` 中可公开访问且非 `index:false` 的文章，排除内部首页模板和测试页。
- Mermaid 已设为 Dagre；生产构建仍包含 Mermaid 的 ELK 依赖 chunk，但首次打开带图文章的浏览器网络请求检查确认没有发起 ELK 资源请求。SVG 图、节点标签和源码区域通过浏览器验收。
- 移动端与桌面搜索共用本地索引和弹窗；浏览器验证正文及代码查询、摘要片段、键盘上下键与 Enter 跳转、Esc 关闭、焦点进入和恢复、索引单次延迟加载、手机视口适配及首页无重复正文搜索。
- 首页、穿透类型说明和术语表明确标记 STCP、SUDP、XTCP 当前不支持，相关选择项已移除。
- 静态 HTML 和 SPA 路由的标题、description、robots、canonical、Open Graph、Twitter 与结构化数据已由共享 SEO 逻辑生成；构建单测遍历页面，浏览器验证 SPA 更新及禁用 JavaScript 时的静态正文与 metadata。搜索索引及 sitemap 均排除内部示例/测试页面。
- 已通过 Docs 单测、类型检查、生产构建、build-output 验证和浏览器验收；最终重复运行结果及提交编号随交付总结报告。
