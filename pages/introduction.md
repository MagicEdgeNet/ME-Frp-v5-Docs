# 项目介绍

ME Frp 为运行在私有网络中的服务提供公网访问入口。它面向个人、开发者和小型团队，常用于游戏联机、远程运维、家庭 NAS、Web 预览和设备调试。

## 它解决什么问题

家庭宽带、校园网、移动网络和多数办公网络通常位于 NAT 或防火墙之后。外部设备无法直接建立到这些网络中某台设备的连接。ME Frp 让内网设备主动连接到公网节点，再由节点接收访问流量并转发到指定的本地地址和端口。

这不等于把整台电脑放到公网。通常只有你配置的隧道入口会转发到对应服务；服务自身的登录、权限和补丁仍由服务管理员负责。

## 一条隧道的组成

- **本地服务**：实际运行在你的设备上的程序，例如 SSH 服务或游戏服务器。
- **Frpc 客户端**：运行在同一内网设备上，负责读取配置并连接节点。
- **ME Frp 节点**：拥有公网接入能力，运行服务端 `Frps` 并提供转发入口。
- **访问入口**：域名、远程端口或受保护的访问方式，供客户端连接。

```mermaid
  visitor[访问者] --> public[节点公网入口]
  public --> server[Frps]

  target --> service[本地服务]
```

## 基本使用流程

1. 注册并登录 ME Frp。
2. 根据设备系统下载客户端，或选择 Docker、fnOS 等安装方式。
3. 在管理面板选择节点和穿透类型，填写本地服务地址。
4. 使用客户端启动隧道。
5. 从外部网络访问分配的域名或端口，并检查服务自身的访问控制。

## 适合的场景

- **开发预览**：临时向同事或客户展示本地 Web 页面。
- **远程管理**：在外访问 SSH、RDP、VNC 或 NAS 管理服务。
- **游戏联机**：为 Minecraft、星露谷物语等服务建立可访问入口。
- **个人服务**：访问音乐库、文件共享或自建网站。

是否适用取决于服务协议、节点能力、网络质量和账户限制。实时游戏或大流量服务应关注延迟、带宽与流量消耗。

## 安全边界

隧道负责网络转发，不会自动替本地服务增加用户认证或加密。对外开放管理端口前，应启用强密码、密钥或应用层认证；不需要时关闭隧道。对于敏感服务，优先使用带访问密钥的类型，并限制可连接来源。
