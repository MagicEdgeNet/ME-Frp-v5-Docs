# RDP 远程桌面配置

:::info 适用场景说明

本指南专为希望将本地 RDP 通过 TCP/UDP 协议暴露至公网的用户设计。

本指南只涉及配置幻缘映射内网穿透的部分，请确保您已部署 VNC Server 后再进行后续操作。

:::

:::warning 安全提醒

使用内网穿透等于 **绕过所有防火墙** 将您的计算机直接暴露于公网中，您需要自行承担由此带来的风险。请使用 **强密码** 并配置系统启用自动更新。

:::

## 启用服务

如果您还没有启用远程桌面的话，请先[打开设置](ms-settings:remotedesktop)，选择 **启用远程桌面** 并启用。

## 确认端口

1. 按 `Win+R` 打开运行窗口，输入 `cmd` 打开**命令提示符**

2. 执行命令

```cmd
netstat -an|findstr :3389|findstr LISTENING
```

3. 检查输出内容，正常情况下应该会输出两行：

```
TCP    0.0.0.0:3389           0.0.0.0:0              LISTENING
TCP    [::]:3389              [::]:0                 LISTENING
```

若输出两行，则本地端口使用 `3389`。若只有 `[::]:3389` 一行，则本地 IP 使用 `::1`，端口使用 `3389`。

## 创建隧道

登录幻缘映射控制台，点击侧边栏的“创建隧道”选项：

![创建隧道](https://img.fastmirror.net/s/2025/10/31/690396107a212.png)

:::info 我应该使用 TCP 还是 UDP？

在远程桌面连接程序中，仅创建一个 TCP 隧道时，界面通常显示一格信号，该显示可能无法准确反映实际网络状况。若在**同一节点**上额外建立一个**远程端口相同**的 UDP 隧道，程序将根据多通道状态更新信号显示，使其更贴近当前实际可用的连接情况。
使用体验不一定会提升很多，请以实际测试为准。

:::

选择带有 TCP 标识的节点，在隧道创建页填入你本地应用的 `IP 地址` 和 `端口`，`远程端口` 建议使用获取随机空闲端口功能：

![创建 TCP 隧道](https://img.fastmirror.net/s/2025/10/31/690398e37c42b.png)

信息填写完成后点击右侧**创建隧道**按钮，若提示 **创建隧道成功** 则隧道创建成功。

## 启动隧道

请您阅读 [启动隧道教程 - 通用客户端](/docs/usage/common) 快速上手，本教程部分不再赘述。

日志中会出现一行 `您可以使用 [xxx] 访问您的服务` 的提示，则您可以在远程桌面连接程序中使用此地址连接。

## 常见问题

### 我修改了我的微软账户密码，为什么不生效？

微软账号密码修改并不会立即同步到电脑上，如果您修改了密码，请尝试下面的方法触发同步：

1. Win+X 后打开 **命令提示行 / PowerShell / Windows 终端**，输入 `runas /u:你的邮箱地址 winver`，按下回车键
2. 输入密码并按回车键，然后关闭弹出的版本窗口
3. 如果您的网络良好，此时您的微软账户密码应该已经同步了

### 提示我的「凭据不工作」

请检查您输入的 用户名 和 密码 是否正确。不要用 PIN 登录，更进一步如果使用了微软账户，请使用微软账户密码。

要获取您当前登录账户的用户名，可以按 Win+X 后打开 **命令提示行 / PowerShell / Windows 终端**，
输入 `whoami`，按下回车键后，您会得到形如 `计算机名/用户名` 的输出，后半部分就是您的用户名。

要确认您的密码正确，您可以尝试在本地使用密码登录一次。
