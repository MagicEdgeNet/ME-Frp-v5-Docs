# Web 应用穿透指南（HTTP/HTTPS）

:::info 适用场景说明

本指南专为希望将本地 Web 应用（如网站、API 服务等）通过 HTTP/HTTPS 协议安全暴露至公网的用户设计，适用于以下常见场景：

- 将个人博客（如 WordPress、Hugo、Ghost、Typecho）对外发布，便于访问与分享
- 暴露自建服务，如 NAS 文件管理、Emby 媒体中心、Vaultwarden 密码管理器等
- 支持微信、支付宝等平台小程序的线上调试与联调测试

本指南只涉及配置幻缘映射内网穿透的部分，请确保您已部署并能在局域网内正常访问目标应用后再进行后续操作。

:::

## 确认隧道类型

幻缘映射支持多种隧道类型，针对 Web 应用的穿透，我们提供三种隧道类型：

| 隧道类型 | 支持的协议      | 是否必须带端口访问 | 绑定自己的域名 | 访问形式 |
|----------|----------------|--------|-------|------------------------------|
| TCP      | HTTP / HTTPS   | 是     | 可选   | `http://frp.example.com:1145` |
| HTTP     | HTTP           | 否     | 必须   | `http://site.example.com`      |
| HTTPS    | HTTPS          | 否     | 必须   | `https://site.example.com`     |

一般情况下，我们把 **HTTP** 和 **HTTPS** 两种隧道类型统称为 **HTTP(S) 隧道**。

:::warning 注意事项

- 使用 **HTTP(S)** 隧道时，如果使用中国大陆节点进行穿透，必须使用 **备案域名**。
- 部分节点对建站功能存在特殊限制，建议在选择节点时仔细查看其备注说明，确认是否适用您的需求。

:::

## 创建隧道

### HTTP(S) 隧道

登录幻缘映射控制台，点击侧边栏的“创建隧道”选项：

![创建隧道](https://img.fastmirror.net/s/2025/10/31/690396107a212.png)

选择带有 HTTP(S) 标识的节点，可在右上角使用 **可建站** 筛选按钮快速定位支持建站的节点：

![可建站筛选](https://img.fastmirror.net/s/2025/10/31/690396156b03e.png)

如下图所示，填入你本地应用的 `IP 地址` 和 `端口`，`域名` 填写你准备绑定的域名：

![创建 HTTP(S) 隧道](https://img.fastmirror.net/s/2025/10/31/69039613af0d9.png)

信息填写完成后点击右侧**创建隧道**按钮，若提示 **创建隧道成功** 则隧道创建成功。

### TCP 隧道

登录幻缘映射控制台，点击侧边栏的“创建隧道”选项：

![创建隧道](https://img.fastmirror.net/s/2025/10/31/690396107a212.png)

选择带有 TCP 标识的节点，在隧道创建页填入你本地应用的 `IP 地址` 和 `端口`，`远程端口` 建议使用获取随机空闲端口功能：

![创建 TCP 隧道](https://img.fastmirror.net/s/2025/10/31/690398e37c42b.png)

信息填写完成后点击右侧**创建隧道**按钮，若提示 **创建隧道成功** 则隧道创建成功。

## 设置解析

:::info 解析设置说明

TCP 隧道不需要进行域名解析设置，直接使用分配的访问地址和端口即可访问；HTTP(S) 隧道需要将域名解析到对应节点的 IP 地址或域名，具体操作请参考以下步骤。

:::

登录幻缘映射控制台，点击侧边栏的“隧道管理”选项：

![隧道管理](https://img.fastmirror.net/s/2025/10/31/6903986405926.png)

选择你的隧道，点击右侧的 **更多** > **查看详情** 选项。在弹出的隧道详情窗口中，找到 **域名解析配置** 部分。

参考你域名注册商提供的解析设置方法，添加一条 `A 记录` 或 `CNAME 记录`，将你的域名解析到隧道详情中提供的 **解析目标**。

- [阿里云](https://help.aliyun.com/zh/dns/add-a-dns-record#h2-cname-2)
- [腾讯云 DNSPod](https://docs.dnspod.cn/dns/help-cname/)
- [Cloudflare](https://developers.cloudflare.com/dns/manage-dns-records/how-to/create-dns-records/)

完成解析设置后，等待 DNS 解析生效（这通常需要几分钟到数小时不等），然后即可通过你的域名访问本地 Web 应用。

## 使用 Cloudflare 代理

Cloudflare 代理会为您的网站自动配置 SSL/TLS，SSL/TLS 设置可在 Cloudflare Dashboard 中更改。

在 `关闭（不安全）` 和 `灵活` 两种模式下，Cloudflare 服务器通过 **HTTP** 协议访问源服务器，而在 `完全`、`完全（严格）` 和 `严格（仅 SSL 源服务器拉取）` 等三种模式下，Cloudflare 服务器通过 **HTTPS** 协议访问源服务器。

如果您的隧道是 **HTTP** 隧道，且您使用 `完全`、`完全（严格）` 和 `严格（仅 SSL 源服务器拉取）` 等三种模式，流量将无法到达您的隧道，用户访问您的网站时会出现幻缘映射默认页。
