# 幻兽帕鲁 (Palworld) 开服联机

:::info 适用场景说明

本指南专为希望将本地 Palworld 服务器通过 UDP 协议暴露至公网的用户设计，支持与世界各地的玩家进行联机游戏。

本指南只涉及配置幻缘映射内网穿透的部分，请确保您已部署 Palworld Server 后再进行后续操作。

:::

## 快速开始

:::tip 开始之前

- 已安装 Palworld 游戏
- 在本地成功创建或启动了服务器
- 已掌握 Palworld 服务器的基本管理

:::

## Palworld 服务器部署

### 在 Windows 上部署

1. 从 Steam 下载 Palworld Dedicated Server 工具
2. 解压到指定目录（建议路径不包含中文和特殊字符）
3. 运行 `PalServer.exe` 以启动服务器

## 确认端口

Palworld 服务器的默认端口是 `8211` (UDP)，且必须使用 UDP 协议。

### Windows 系统

1. 按 `Win+R` 打开运行窗口，输入 `cmd` 打开**命令提示符**

2. 执行命令

```cmd
netstat -an|findstr :8211|findstr LISTENING
```

3. 如果输出显示 `LISTENING` 状态，则说明服务器正在监听此端口

### Linux/Docker 系统

```bash
netstat -tulnp | grep 8211
# 或查看 Docker 容器日志
docker logs <container_name>
```

## 创建隧道

确认本地端口后，开始创建 UDP 隧道。

登录幻缘映射控制台，点击侧边栏的"创建隧道"选项：

![创建隧道](https://img.fastmirror.net/s/2025/10/31/690396107a212.png)

选择带有 **UDP** 标识的节点，在隧道创建页填入你本地应用的 `IP 地址` 和 `端口: 8211`，`远程端口` 建议使用获取随机空闲端口功能：

![创建 UDP 隧道](https://img.fastmirror.net/s/2025/11/16/6918b245dfb56.png)

信息填写完成后点击右侧**创建隧道**按钮，若提示 **创建隧道成功** 则隧道创建成功。

## 启动隧道

请您阅读 [启动隧道教程 - 通用客户端](/docs/usage/common) 快速上手，本教程部分不再赘述。

日志中会出现一行 `您可以使用 [xxx] 访问您的服务` 的提示，客户端可以使用这个地址加入您的服务器。

## 常见问题

### 玩家掉线频繁

- **原因**：通常是网络延迟或**服务器内存满了**
- **解决**：
  1. 选择 UDP 延迟较低的节点
  2. 检查服务器日志是否有错误信息
  3. 降低服务器的最大玩家数
