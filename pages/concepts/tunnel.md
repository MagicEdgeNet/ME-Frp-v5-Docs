# 隧道与代理

在 ME Frp 中，“隧道”通常指一组把公网访问入口连接到本地服务的配置；“代理”则是 Frp 中描述具体转发规则的对象。管理面板会把创建和管理代理的流程呈现为创建隧道。

## 隧道

隧道配置描述客户端如何连接节点，以及收到数据后应送到哪里。常见信息包括穿透类型、本地 IP 和端口、节点、远程端口、域名和访问凭据。

一台设备可以运行多个代理。每个代理应对应一个明确的服务和访问方式。

## 代理

代理把一类入口和一个本地目标关联起来。例如：

```text
TCP 公网入口 : 32000 -> 192.168.1.20:22
```

访问者连接节点的 32000 端口后，数据经客户端转发至内网主机的 SSH 22 端口。

## 节点

节点是运行 `frps` 并提供公网接入的服务器。不同节点可能在地域、延迟、可用类型、端口、带宽和账户权限上有所不同。创建隧道时选择的节点决定入口由哪里接入。

## 地址与端口

- **本地 IP / 端口**：内网服务实际监听的位置，例如 `127.0.0.1:8080`。
- **远程端口**：节点用于接收访问的公网端口，通常由平台分配或限制。
- **域名**：供 HTTP/HTTPS 访问使用的主机名，具体规则取决于平台配置。

本地端口与远程端口属于两端不同的网络位置，不必相同。

## 流量与连接

访问者和服务之间传输的数据经过客户端与节点转发，因此路径、网络拥塞、节点负载和服务本身都会影响延迟与吞吐量。数据计量、连接数和端口策略以 ME Frp 当前账户和节点规则为准。
