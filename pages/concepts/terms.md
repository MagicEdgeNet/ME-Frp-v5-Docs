# 术语表

| 术语 | 含义 |
| --- | --- |
| 内网 | 使用私有地址、通常不能被互联网直接访问的网络。 |
| 公网 | 可以通过互联网路由到达的网络或地址。 |
| NAT | 网络地址转换。路由器或运营商设备常用它共享地址，也会影响外部主动连接内网设备。 |
| 内网穿透 | 通过内网设备主动连接公网节点，让外部流量能够沿该连接到达内网服务。 |
| Frpc | Frp 客户端程序，通常运行在提供服务的内网设备上。 |
| Frps | Frp 服务端程序，运行在提供公网接入的节点上。 |
| 节点 | 运行服务端并接受客户端连接的 ME Frp 服务器。 |
| 隧道 | 把公网入口、客户端连接和本地服务关联起来的一组配置。 |
| 代理 | Frp 中的一条具体转发规则，描述入口与本地目标的对应关系。 |
| 本地服务 | 内网设备上真正处理请求的程序，例如 Web、SSH 或游戏服务器。 |
| 本地地址 | Frpc 要连接的内网 IP 和端口。 |
| 远程端口 | 节点对外提供访问的端口，与本地端口可以不同。 |
| 控制连接 | 客户端与服务端之间用于认证、心跳和管理代理的连接。 |
| 数据流量 | 访问者与本地服务之间实际传输的内容。 |
| TCP | 面向连接、保证顺序和重传的传输协议。 |
| UDP | 面向数据报、不保证重传和顺序的传输协议。 |
| 端口映射 | 把节点上的端口映射到内网服务的本地端口。 |
| 域名映射 | 依据域名把 HTTP/HTTPS 请求路由到对应的内网 Web 服务。 |
| STCP | Frp 上游的私有 TCP 代理类型，通常需要授权密钥；ME Frp 当前暂不支持，不能在本平台创建或使用。 |
| XTCP | Frp 上游用于尝试点对点传输的代理类型；ME Frp 当前暂不支持，不能在本平台创建或使用。 |
| SUDP | Frp 上游的私有 UDP 代理类型，通常使用授权信息；ME Frp 当前暂不支持，不能在本平台创建或使用。 |

术语在不同 Frp 版本和管理面板中可能有不同的显示名称。具体配置以 ME Frp 当前面板及客户端版本为准。
