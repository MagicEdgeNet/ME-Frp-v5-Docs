# 穿透类型

穿透类型决定流量如何从 ME Frp 节点到达本地服务。**ME Frp 当前支持 TCP、UDP、HTTP 和 HTTPS；STCP、SUDP、XTCP 暂不支持。** 请以管理面板中实际可选的类型和当前客户端版本为准。

:::warning 当前暂不支持
STCP、SUDP 和 XTCP 是 Frp 上游项目中的代理类型，但目前不能在 ME Frp 创建或使用。下方对它们的介绍仅用于解释上游术语，不代表 ME Frp 提供相应能力，也不应作为配置建议。
:::

## TCP

面向连接的通用传输方式。适合 SSH、RDP、VNC、Minecraft Java、数据库和多数不依赖 UDP 的服务。

优点是兼容性好、行为稳定；缺点是所有数据都按 TCP 传输，无法替代真正的 UDP 服务。

## UDP

面向数据报的传输方式。适合部分游戏、语音、实时发现和其他明确使用 UDP 的程序。客户端、节点及具体服务均需支持相应的 UDP 转发能力。

## HTTP

用于 HTTP 网站和 HTTP API。通常可以使用域名访问，由节点根据域名把请求转给本地 Web 服务。它不是任意 TCP 服务的通用替代方案。

## HTTPS

用于 HTTPS 网站。证书终止位置、TLS 模式和本地服务是否已经启用 HTTPS 需要按平台和教程配置。不要把 HTTPS 类型简单理解为“给任意端口自动加证书”。

## Frp 上游类型（ME Frp 暂不支持）

以下类型属于 Frp 上游术语，仅供理解已有配置或相关资料时参考。ME Frp 当前不支持这些类型，不能在本平台创建或使用。

### STCP

Frp 上游的私有 TCP 代理类型，通常通过访问密钥限制访问方。**ME Frp 当前暂不支持 STCP。**

### XTCP

Frp 上游用于尝试建立点对点传输的代理类型，连接效果取决于网络条件。**ME Frp 当前暂不支持 XTCP。**

### SUDP

Frp 上游的私有 UDP 代理类型，通常使用授权信息限制访问方。**ME Frp 当前暂不支持 SUDP。**

## 选择速查

| 你的服务 | 优先考虑 |
| --- | --- |
| SSH、RDP、VNC、Minecraft Java 等 TCP 服务 | TCP |
| 明确使用 UDP 的游戏或实时服务 | UDP |
| 本地网站或 HTTP API | HTTP / HTTPS |

请根据本地服务实际使用的传输协议选择类型；无法确定时，先查看服务官方文档或监听端口说明。[查看实际场景配置](/docs/app/minecraft)
