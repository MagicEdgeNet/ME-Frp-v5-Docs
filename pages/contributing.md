# 参与贡献

本文档站接受社区贡献。提交内容前请先阅读本页，特别是其中的[贡献者许可协议](#贡献者许可协议)。

本页是站点正文里的说明；仓库根目录的 `CONTRIBUTING.md` 讲的是代码与站点开发的提交流程，两者互补。

## 文档许可

本站除特别说明外，原创文档内容采用 [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)（Creative Commons Attribution 4.0 International）向公众授权。你可以自由复制、分发、改编、翻译和汇编，包括商业用途，条件是保留署名并说明是否作出修改。

站点代码单独采用 MIT License，见仓库根目录的 `LICENSE`。

要与项目方约定的授权分两层，互不冲突：

- **第一层**：你通过下面的贡献者许可协议，把所贡献内容的相应权利授予项目方。
- **第二层**：项目方再以 CC BY 4.0 把内容发布给所有读者。

也就是说，你的作品不会因为提交而失去 CC BY 4.0 的公开可用性，只是额外允许项目方灵活地再利用与再授权。

## 贡献前须知

当你对文档作出贡献时，表示你已知悉：你对所创作的内容拥有著作权且有权授权。如果你不拥有对应内容的财产权，或未获著作权人书面委托允许提交，请勿提交。提交即代表你确认有权将对应内容贡献给项目。

请只提交有权分发的内容和图片，保留必要的第三方署名与原许可；不要提交账户凭据、Token 或未经打码的个人信息。

## 提交 Pull Request 时

在 Pull Request 的评论中完整包含以下文本：

```text
我已悉知并确认对本次贡献的内容有权提交。

本人已完整阅读贡献者许可协议原文的所有内容并同意其中的所有条款，且我已确认本次提交代表向我们授予了所贡献的内容的：

1) **永久、全球、非排他、免费、不可撤销**的**复制权、发行权、改编权、翻译权、汇编权以及由我们向第三人再授权上述权利的许可**。
2) 允许我们通过不特定方式向第三人**展示、修改、再分发、再授权**本次贡献的内容。
3) 允许参与贡献的其他贡献者对贡献的内容进行修改，以及展示经我们和其他贡献者修改后的内容。
4) 本次贡献如存在相关专利，一并授予我们**永久、全球、非排他、免费、不可撤销**的使用和再授权贡献中相关专利的权利。
5) 本人在本项目中的既往贡献，一并按本协议授权给我们。
```

## 内容与格式要求

- 新文档使用一个清楚的一级标题，正文使用二级及以下标题，不按排版需要跳过层级。
- 标题简短清晰，不堆砌关键词；`title` 与 `navTitle` 可按已有约定分别保留。
- 代码块注明语言。示例中不要出现真实 Token、密码、内网拓扑或个人信息。
- 使用标准 Markdown；提示框写作 `:::info 标题` / `:::warning 标题` / `:::tip 标题`，以独占一行的 `:::` 结束。
- 不支持执行脚本、组件、任意 HTML 或 frontmatter，正文中的 HTML 会被转义。
- 内部链接使用 `/docs/usage/client` 这类稳定站点路径，不带 `.md`。
- 图片放入 `assets/`，用 `/docs-assets/文件名.png` 引用，写清替代文本，压缩后再提交。

新增页面需要在 `manifest.json` 中登记，分组与页面数组的顺序即侧栏顺序。目录、路径调整请同时说明旧链接如何保持可访问。
