## 为什么就是启动不了

1. 使用 PowerShell 启动时，请确保你在 `mefrpc.exe` 前面加上了 `./`，启动命令类似如下:

```bash
./mefrpc.exe -t 访问密钥 -p 隧道Id
./mefrpc.exe -c frpc.toml
./mefrpc.exe
```

2. 使用命令提示符 (cmd) 则可以去除 `./`，启动命令类似如下:

```bash
mefrpc.exe -t 访问密钥 -p 隧道Id
mefrpc.exe -c frpc.toml
mefrpc.exe
```

## 一个 mefrpc 可以连接多条隧道吗

我们的 mefrpc **快捷启动** 已支持多节点、多隧道模式，现在可以连接位于不同节点的多个隧道了。

在 **使用配置文件启动** 时，一个 mefrpc 进程只能连接一个 **节点**，这就是说：

- 如果这几条隧道不在同一个节点：不能，必须开启多个 frpc 进程
- 如果这几条隧道都在同一个节点上：可以在一个 frpc 进程中连接多条隧道

## 如何通过一个 mefrpc 开启多条隧道

如果您使用 **快捷启动** 启动 mefrpc，只需要在启动参数中加上半角逗号 `,` 分隔的其他隧道 ID 即可，例如：

```bash
mefrpc -t <访问密钥> -p <隧道ID 1>[,隧道ID 2[,隧道ID 3...]]
```

如果您使用 **配置文件** 启动 frpc，所有隧道位于同一节点时可以通过合并配置文件来此目的。

## 解析配置文件失败

在使用配置文件启动时配置文件格式有误，请使用代码编辑器如 [Visual Studio Code](https://code.visualstudio.com/download) 等查看是否存在格式错误。

常见错误包括编码问题、JSON 双引号误写成单引号等。

## WebUI 怎么用？有哪些参数？

MEFrpc WebUI 是幻缘映射发行的 FRPC 附带的特有功能（其他渠道的 FRPC 没有），只需在 WebUI 中登录您的幻缘映射账户，即可通过网页控制隧道的启停。

WebUI **默认做了禁止穿透到外网的限制**，防止他人使用您的宿主机进行意外的穿透，不过您可以使用 `--webui-allow-public-access true` 绕过这个限制（默认密码下不可使用）。

默认密码为 `admin`，可通过配置文件或命令行参数 `--webui-pass` 修改。您还可以用 `--webui-addr` 指定绑定的地址（默认 `127.0.0.1`，您可能想要改成内网 IP），`--webui-port` 指定绑定的端口。 

若您需要在其他情况下也启用 WebUI （默认只有在没有指定快捷启动/配置文件时才会启动），可附加 `-w` 参数。

## 在 Termux 上报错「dial tcp: lookup xxx on [::1]:53: connection refused」

其中 xxx 应该是一个域名。这个问题主要由以下几个因素导致：

1. mefrpc 是在标准 Linux 环境下使用 `CGO_ENABLED=0` 编译的，但 Termux 是一个特殊的 Android Unix 环境，两者在系统调用和 C 库实现上存在差异。
2. Android 系统不使用标准的 `/etc/resolv.conf` 文件进行 DNS 配置。当 Go 程序使用纯 Go 实现的 netgo 时，它会尝试读取这个不存在的文件，然后回落到一个错误的地址上导致 DNS 解析失败。

解决方案：

1. 不使用 Termux 运行 mefrpc 程序
2. 使用配置文件启动，并在配置文件里指定 `dnsServer` (string) [gofrp 参考文档](https://gofrp.org/zh-cn/docs/reference/client-configures/)
3. 使用配置文件启动，不过这次自行解析节点域名为 IP 并修改获取到的配置文件

如果你看不懂第二条，看起来你不是很适合使用 Termux，继续这样做可能会给你带来无尽的麻烦。

如果您希望自行编译官版 frp，可以参考 [Cross-compiling Go for Termux With Working DNS](https://dave.engineer/blog/2025/11/cross-compiling-go-android/) 这篇文章。

## 隧道为什么是离线的？

- 你启动隧道了吗？
- 你会启动隧道吗？

如果看得懂使用文档请您[按照文档说明进行启动](/docs/introduction)，看不懂建议重修小学语文和信息技术基础知识。

- 启动了，启动成功了吗？

只有出现`启动隧道成功，您可以通过 XXX 访问您的服务` 字样后，隧道才算启动成功。您可参照接下来的内容进行筛查。看不懂建议去医院挂眼科而不是骚扰任意一位管理员的私信。

- 我一直启动不了啊，能不能退款啊？

**不能**，虚拟商品不支持退款，且**创建隧道并不需要花任何一分钱**。若你投诉我们的支付接口，我们会把你的账户封禁处理，并同步到内网穿透联盟黑名单，**这会使得你无法使用市面上大部分内网穿透服务**。  
遇到这种情况请你带着日志寻求管理或者交流群内群友的帮助，而不是发表诸如“有人吗” “有大佬能帮我吗” “怎么办怎么办” 的言论，否则建议你立刻前往医院神经内科挂号问诊，或者把小学道法课本拿起来多翻翻。
