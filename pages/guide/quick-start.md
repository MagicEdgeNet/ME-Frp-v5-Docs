# 快速开始

本页带你从账户准备到访问第一条隧道。不同客户端界面略有差异，但流程相同：准备本地服务、创建隧道、启动客户端、从外部网络验证。

## 准备

1. [注册或登录 ME Frp](https://www.mefrp.com/)。
2. 确认你要公开访问的程序已经在本机或局域网内正常运行。
3. 记下服务监听的本地 IP 和端口，例如 `127.0.0.1:8080`。
4. 查看[穿透类型说明](/docs/concepts/protocols)，选择与服务协议匹配的类型。

不要先创建隧道再猜本地端口。先在本机验证服务可以访问，排错会更容易。

## 创建隧道

在管理面板进入隧道管理并创建代理：

1. 选择可用节点。
2. 选择 TCP、UDP、HTTP 或 HTTPS 等类型。
3. 填写本地 IP 与端口。
4. 保存配置，并记录平台分配的远程端口、域名或启动信息。

本地端口指服务所在的内网位置；远程端口指访问者连接节点时使用的入口。两者可以不同。

## 安装并启动客户端

从[客户端教程](/docs/introduction)选择适合系统的版本，使用面板提供的配置启动 `Frpc`。也可选择 [Docker](/docs/usage/docker) 或 [fnOS](/docs/usage/fnnas) 方式。

客户端成功连接后，面板应显示隧道在线。若连接失败，先检查配置是否属于当前账户和节点、系统时间是否正确，以及出站网络是否允许客户端连接。

## 验证访问

使用手机蜂窝网络或其他外部网络访问分配的地址，确认请求能到达本地服务。只在同一局域网内访问不足以验证公网入口。

如果无法访问：

- 确认本地服务仍在运行，并监听了正确地址和端口。
- 检查代理类型与应用使用的协议是否一致。
- 检查客户端在线状态、节点限制、域名和远程端口。
- 对 Web 服务查看[网站访问排查](/docs/faq/site-inaccessible)。
